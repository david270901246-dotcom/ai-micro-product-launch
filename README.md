## 这是什么

这是一套被真实跑通的流程，不是教程拼凑：

1. 刷到一个收费的 AI 测评网站，决定复刻它
2. 一人 + AI 助理做出自己的产品「初见雷达」（AI 第一印象报告）
3. 防白嫖兑换码体系、Cloudflare Worker 接口、验码对接，全部自建
4. 在 Gumroad 以 **$4.99** 上架，License Key 验码自动交付，端到端实测通过
5. 之后又用同一套打法做了第二个产品「老照片开口说话」，验证打法可复用

全程的真实账单：Gumroad 无月费（卖出才抽成）、GitHub Pages 免费、Cloudflare Workers + KV 免费额度、EdgeOne 免费套餐、免费版视觉大模型。**闲置时零固定成本**，天花板是免费额度（本案例设全站 100 份/天）。

## 9 个阶段（目录）

0. **选题与做减法** —— 从参考产品提取功能清单，只留一个最锋利的卖点
1. **产品定义** —— 先定输出结构再写代码，报告型产品先定字段
2. **零成本技术栈** —— 静态站 + Serverless 接口 + 免费模型，闲置零成本
3. **防白嫖兑换码体系** —— 一人一码、成功才扣次、每日熔断，规则先于代码
4. **渠道决策** —— 国内与海外渠道逐项过清单，定了不横跳
5. **Gumroad 上架全流程** —— 定价、销售上限、License Key、付款后闭环，一个都不能漏
6. **验码对接** —— 最容易栽的一步，有一个不报错的大坑等着
7. **端到端实测清单** —— 发布当天用真买家流程全链路走一遍
8. **宣传与流量** —— 平台不带流量，冷启动靠自己的内容渠道，产品故事本身就是素材
