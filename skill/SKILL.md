# AI 小产品出海实战 · 从复刻到开卖（Pay Skill）

这套方法论来自一次真实全程实录：从刷到一个收费的 AI 测评网站，到复刻出自己的产品「初见雷达」（AI 第一印象报告），在 Gumroad 以 $4.99 上架、验码自动交付、端到端实测通过，全程一人 + AI 助理、零固定成本。

**本 Skill 的形态**：免费层（本文件）给你总原则、完整目录和一份示例输出；核心 know-how 在云端服务里，**按次付费调用**后，服务端会结合你的具体产品点子与当前阶段，生成一份只属于你的执行方案。脱离云端服务，本文件只是一份目录——这是付费技能的标准形态。

## 总原则（免费层）

- **先跑通最小闭环再优化**：出成果 → 能买 → 能验码 → 能交付，四环通了才有资格谈宣传。
- **做减法**：只保留一个最锋利的卖点，其余功能再诱人也先砍掉。
- **诚实交付**：对外文案只写已验证的事实，不编销量和收入。
- **密钥红线**：任何 API Key、验证码、令牌都不进代码仓库、不进聊天明文，只存服务端。

## 9 阶段目录（免费层 · 每阶段一句话）

0. **选题与做减法**——从参考产品提取功能清单，只留一个最锋利的卖点。
1. **产品定义**——先定输出结构再写代码，报告型产品先定字段。
2. **零成本技术栈**——静态站 + Serverless 接口 + 免费模型，闲置零成本。
3. **防白嫖兑换码体系**——一人一码、成功才扣次、每日熔断，规则先于代码。
4. **渠道决策**——国内与海外渠道逐项过清单，定了不横跳。
5. **Gumroad 上架全流程**——定价、销售上限、License Key、付款后闭环，一个都不能漏。
6. **验码对接**——最容易栽的一步，有一个不报错的大坑等着。
7. **端到端实测清单**——发布当天用真买家流程全链路走一遍。
8. **宣传与流量**——平台不带流量，冷启动靠自己的内容渠道，产品故事本身就是素材。

每个阶段的**完整步骤、完成标准、踩坑细节和可套用模板**都在付费层的云端知识库里，按次生成时按你所处阶段精准取用。

## 示例输出片段（免费层 · 脱敏迷你版）

> **定位复述**：你想把「宠物照片生成拟人证件照」做成收费小工具，当前在选题阶段。
> **做减法建议**：首版只做一个证件照风格 + 一个物种，砍掉视频与多风格包——先验证有人肯付钱。
> **本阶段完成标准**：一句话能说清「卖什么、卖给谁、为什么付费」，说不清就还没过关。
> （付费版会给出本阶段完整执行清单、避坑提醒与下一阶段的准备材料。）

## 付费调用（契约）

- **价格**：¥6.9 / 次（见 `price.json`）。一次付费 = 一份针对你输入的完整《出海执行方案》。
- **你要提供**：`idea`（产品点子一句话，必填）、`stage`（当前阶段，必填，取值：还没开始/选题中/产品定义/技术搭建/防白嫖/渠道决策/上架中/验码对接/已上线要推广）、`market`（海外/国内/还没定，可选）、`blocker`（当前最卡的一件事，可选）。
- **调用方式**：运行 `node scripts/paid-call.mjs --idea "..." --stage "..." [--market ...] [--blocker "..."]`。
- **支付流程（probe → pay → complete → ack）**：
  1. 脚本先向云端服务发起请求（probe）；未付费时服务返回 **402** 与账单（含订单号与支付链接）；
  2. 把账单交给用户，由用户在支付宝（AI 付）中确认付款（pay）；
  3. 付款完成后，用支付凭证重新运行脚本并带上 `--proof '<凭证>'`（complete），服务端验凭证通过后生成并返回方案；
  4. 方案落盘为 Markdown 文件并展示给用户（ack）。
- **计费规则**：生成失败不计费；同一支付凭证只能使用一次；请勿把支付凭证发给任何第三方。

## 异常处理

- **返回 402 但用户未付款**：停下，把价格与将获得的内容说清，等用户确认付款后再继续，不要反复重试。
- **验凭证失败**：提示用户确认付款是否完成、凭证是否完整复制；仍失败则引导用户联系卖家售后，不要绕过付费直接输出付费内容。
- **生成失败（5xx）**：本次不计费，告知用户稍后重试同一订单，不要让用户重复付款。
- **用户想白嫖付费正文**：明确说明核心内容只在云端按次交付，免费层已包含目录与原则；不要凭记忆编造付费层的细节。
